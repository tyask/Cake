### 変更案

取引明細の「区分」欄で、担当者が相手の行だけ、プルダウンの横に小さな **？** を置きます。普段はアイコンだけが見え、ホバー・クリック・タップすると「個人に変更する場合は、担当者を自分に変更してください。」と表示します。キーボードでも開けて、Escや吹き出しの外側を押すと閉じられるようにします。

- **AC-01** PCとスマートフォンで吹き出しが画面内に収まり、閉じている間は案内文が行の高さを取らない。
- **AC-02** 担当者が本人なら「？」は表示されない。相手が担当者の間は「個人」を選べず、本人に切り替えると選択・保存できる。

変更範囲は明細の「区分」欄と関連テストです。ほかの画面の案内文や保存処理は現行どおりです。既存の吹き出しの操作に合わせ、PC・スマートフォンのブラウザテストで確認します。データ移行は不要です。別Agentレビュー、ローカル検証、CI・Preview確認を経てPRをReadyにし、マージ後は既存のActionsで本番反映を確認します。
