先ほどのテンプレート遵守の修正に追加し、次の流れに統一します。

1. 開発を依頼する。
2. 開発計画を提示し、承認を得る。
3. Issueを作成・更新し、保存済みの本文とURLを提示して承認を得る。
4. ブランチ・worktreeを作成し、開発を開始する。

受入条件は次のとおりです。

- **AC-01**：対象テンプレートを読み、該当項目・規定の見出し・受入条件のチェックリストを照合する。
- **AC-02**：計画承認とIssue承認を区別し、Issue承認前はブランチ作成・開発へ進まない。
- **AC-03**：両方の承認を別々に記録する。同じ承認内容での再開や、進捗・検証結果の追記では承認を求め直さない。

AGENTS.md、README.md、関連する開発・AI-DLC手順書の計6ファイルと案件記録を更新します。文書チェックと別Agentレビュー、CI・自動Preview/statusを確認し、PRのReadyまで進めます。
