月別キャッシュを追加する計画に変更します。既存の[Issue #168](https://github.com/tyask/Cake/issues/168)の内容に、次を追加します。

- ホームを表示している間、参照した月の集計結果を最大12か月分、メモリに保持します。
- 取得済みの月に戻った場合は、通信せず表示します。
- 保存・取込・清算・手動更新・ワークスペース変更・ホームからの移動で破棄します。参加者の変更を検知した場合も破棄します。
- キャッシュを表示しても、清算情報・履歴が過去の状態に戻らないようにします。

受入条件は、**AC-07：取得済み月への再訪で通信しない、AC-08：更新時に確実に破棄・再取得する、AC-09：遅い応答や古い清算情報を再利用しない**、を追加します。通信回数・上限超過・破棄・応答逆転のテストと、既存の全体検証を行います。

他端末での変更は、更新ボタンやホームへの入り直しで反映します。
