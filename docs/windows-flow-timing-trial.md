# Windows native workflow timing trial

This documentation-only trial measures branch creation, commit and push, draft PR creation, local checks, and ordinary GitHub CI from a prepared Windows environment.

This is a test artifact. Keep the PR as a draft; no merge is requested. Application behavior and deployment settings are unchanged.

The warm environment uses Node 24.13.0, prepared npm dependencies, and official Playwright Chromium. Local regression tests use a process-only LF Git setting. Detailed timings are recorded in the draft PR description.

Preview deployment, application authentication, and real database operations are outside this trial.
